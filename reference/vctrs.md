# Construct a `ccn`/`ccnr` object

Construct a `ccn`/`ccnr` object

## Usage

``` r
ccn(x = character())

ccnr(
  ccn = character(),
  entity = character(),
  state = character(),
  number = character(),
  type = character()
)

get_index(x)

# S3 method for class 'ccn'
get_index(x, ...)
```

## Arguments

- x:

  `<chr>` A vector of CCNs.

- ccn:

  `<chr>` vector of ccns

- entity:

  `<chr>` vector of ccn entity types

- state:

  `<chr>` vector of state codes

- number:

  `<chr>` vector of sequence numbers

- type:

  `<chr>` vector of facility types

- ...:

  description

## Value

An S3 vector of class `<ccn>` or `<ccnr>`

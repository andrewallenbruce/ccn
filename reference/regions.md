# CMS Regional Office Codes

CMS Regional Office Codes

## Usage

``` r
regions
```

## Format

### `regions`

A data frame with 109 rows and 5 columns:

- code:

  Region number

- roman:

  Region roman numeral

- state:

  State abbreviation

- office_abbr:

  Regional office city abbreviation

- office_full:

  Regional office city full name

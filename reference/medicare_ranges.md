# CCN Medicare Facility Ranges

CCN Medicare Facility Ranges

## Usage

``` r
medicare_ranges
```

## Format

### `medicare_ranges`

A data frame with 43 rows and 6 columns:

- start:

  Medicare facility range start

- end:

  Medicare facility range end

- range:

  Medicare facility range label

- abbr:

  Medicare facility abbreviation

- desc:

  Medicare facility description

- iv:

  Medicare facility range [ivs::iv](https://github.com/DavisVaughan/ivs)
  vector
